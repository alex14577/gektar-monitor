gektar-gen-license — утилита выпуска лицензионных ключей
=========================================================

УСТАНОВКА
---------
Windows: положите gektar-gen-license.exe в любую папку. Запускать можно
         прямо оттуда — установка не требуется.

Linux:   положите gektar-gen-license в любую папку, выполните:
           chmod +x gektar-gen-license


ВЫПУСК КЛЮЧА (интерактивный режим)
----------------------------------
Двойной клик по файлу (Windows) или запуск из терминала (Linux):

  ./gektar-gen-license

Программа задаст три вопроса:

  1. Дата начала действия ключа (YYYY-MM-DD)
     Например: 2026-06-01

  2. Дата окончания действия ключа (YYYY-MM-DD)
     Например: 2026-12-31

  3. Папка сохранения файла ключа (Enter = рядом с программой, только в интерактивном режиме)

После ответов программа создаёт файл license.key в указанной папке.
Передайте этот файл клиенту — он помещает его в корневую папку fis-monitor
(рядом с run.sh / run.bat, НЕ внутрь bin/).


КЛЮЧ В СКРИПТАХ (CLI режим)
---------------------------
Для автоматизации или пакетного выпуска используйте подкоманду issue:

  gektar-gen-license issue --nbf 2026-06-01 --exp 2026-12-31 --out C:\Keys

  Параметры:
    --nbf YYYY-MM-DD   Дата начала действия (not-before)
    --exp YYYY-MM-DD   Дата окончания действия (expiry, включительно)
    --out <папка>      Папка назначения; файл всегда называется license.key

Пример для Linux:
  ./gektar-gen-license issue --nbf 2026-06-01 --exp 2026-12-31 --out /tmp/keys


ФОРМАТ ФАЙЛА КЛЮЧА
------------------
Файл license.key содержит одну строку вида:

  v2.<payload>.<signature>

Клиент кладёт этот файл в корневую папку fis-monitor — рядом с run.sh / run.bat
(НЕ внутрь bin/). Программа проверяет ключ при каждом запуске и отказывается
стартовать с истёкшим или недействительным ключом.


ВАЖНО
-----
Утилита gektar-gen-license содержит секрет подписи и предназначена только
для авторизованных партнёров компании.

НЕ передавайте файл .exe / gektar-gen-license третьим лицам — в отличие
от fis-monitor, этот инструмент позволяет выпускать неограниченное количество
ключей.

При первом запуске Windows может показать предупреждение:
  «Windows защитила ваш компьютер» / «Неизвестный издатель»

Нажмите «Подробнее» (More info) → «Выполнить в любом случае» (Run anyway).
Это стандартное предупреждение SmartScreen для неподписанных бинарей.


УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ
--------------------------
Ошибка «ERROR: --exp is before --nbf»
  Проверьте порядок дат: --nbf должна быть раньше --exp.

Ошибка «ERROR: --out does not exist»
  Убедитесь, что указанная папка существует перед запуском.

Ошибка «Could not write license.key»
  Проверьте права записи в папку назначения.

Ключ не принимается fis-monitor (INVALID или EXPIRED)
  Убедитесь, что дата на машине клиента не выставлена в прошлое (anti-rollback
  проверка: дата запуска должна быть >= --nbf и <= --exp).
