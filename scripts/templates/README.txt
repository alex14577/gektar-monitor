fis-monitor — Мониторинг свободных гектаров (Дальневосточный гектар)
======================================================================

ТРЕБОВАНИЯ
----------
- Операционная система с графической оболочкой (GUI): Ubuntu Desktop, Windows 10/11.
  Программа использует браузер Chromium для входа через Госуслуги — без рабочего дисплея
  не работает.
- Свободное место на диске: ~100 МБ для данных и логов.
- Интернет: нужен для подключения к сайту hektar.gov.ru и серверам Госуслуг.

УСТАНОВКА
---------
1. Распакуйте архив в любую папку (например: ~/fis-monitor или C:\fis-monitor).
2. Убедитесь, что структура папок выглядит так:
     fis-monitor/
       bin/
       browsers/
       run.sh        (Linux)
       run.bat       (Windows)
       README.txt

ЗАПУСК
------
Linux:
  chmod +x run.sh   # только первый раз
  ./run.sh

Windows:
  Двойной клик по run.bat
  (или в командной строке: run.bat)

После запуска откройте браузер и перейдите по адресу:
  http://127.0.0.1:8000

ПЕРВЫЙ ЗАПУСК
-------------
При первом запуске программа создаст папку var/ рядом с архивом — там хранятся
база данных и логи. Затем откроется мастер настройки:
  Шаг 1: Выбор регионов мониторинга
  Шаг 2: Настройка e-mail уведомлений (SMTP)
  Шаг 3: Список получателей
  Шаг 4: Тестовое письмо

Для входа на сайт Дальневосточного гектара нажмите кнопку «Войти через Госуслуги»
на главном экране — откроется браузер Chromium для авторизации.

ОСТАНОВКА
---------
Linux:   Ctrl+C в терминале, где запущен run.sh
Windows: Закройте окно командной строки или нажмите Ctrl+C

ОБНОВЛЕНИЕ
----------
Для обновления распакуйте новый архив в отдельную папку и запустите run.sh / run.bat
из новой папки. Папку var/ можно скопировать из старой папки — данные совместимы
между версиями в рамках той же мажорной версии.

ПОДДЕРЖКА
---------
При проблемах приложите содержимое папки var/logs/ к обращению в поддержку.
