# MVP — финальный скоуп

> Решения зафиксированы в [[decisions-log]] 12.05.2026. Этот файл — отражение MVP-функциональности.

## Что входит в MVP

### Бэкенд
- Локальный FastAPI на `http://127.0.0.1:8080` (НЕ `0.0.0.0`)
- Single-instance защита через lock-файл
- Цикл мониторинга в background-task
- Парсер списка `?per-page=10&sort=-DATE_CREATE` + ранний выход на знакомом id
- Lazy enrichment деталей (первая страница при старте, дальше обычный цикл)
- Playwright persistent context для логина через ЕСИА
- Hosts whitelist Playwright: только `xn--80aaggvgieoeoa2bo7l.xn--p1ai` и `esia.gosuslugi.ru`
- SQLite + WAL, гибрид-схема (см. [[db/schema|db/schema.sql]])
- CSRF: `Origin`-check + secure-cookie
- File-watch на `config.json` для reload без рестарта

### Каналы уведомлений (плагин-архитектура)
- **Браузер**: Notification API + SSE/polling
- **Email**: через бот-ящик с дефолтным SMTP в config; пользователь может переопределить SMTP через панель; список получателей через панель

### Веб-UI (страницы)
- **Главная**: список новых необнотифицированных лотов
- **Настройки → Регионы/Фильтры**: какие регионы мониторим, минимальная площадь и т.п.
- **Настройки → Уведомления**: список плагин-каналов с тумблерами и формами (Email + браузер в MVP)
- **Настройки → Расписание**: интервал цикла, часовой пояс
- **Настройки → Сессия**: статус ЕСИА, кнопка «Войти заново», журнал запросов
- **Дизайн** делается пользователем отдельно

### Прочее
- Heartbeat-сводка раз в сутки (опционально, чекбокс в настройках, по умолчанию **выключено**)
- Idempotency notifier: таблица `notifications(lot_id, channel, sent_at)`
- Self-diagnostic export через панель — zip с логами и state.db (секреты замаскированы)
- Логирование: JSON-файлы, ротация посуточно, удержание 30 дней
- Журнал запросов: `requests.jsonl` для прозрачности

### Архитектурно заложено (но в коде MVP минимальные следы)
- Каталог с фильтрами/картой — БД-схема и API поддерживают, но UI каталога делаем в v2
- Дополнительные каналы (Telegram, ntfy, Discord, Slack, ВК, SMS, Webhook) — плагин-интерфейс готов, реализация по запросу
- Forward-compat с хостингом — переменная окружения `MODE=local|server`, чтобы тот же код работал на VPS в будущем

## Что НЕ входит в MVP (v2 и далее)

### v2 (после feedback от пользователя)
- **Каталог** с фильтрами, FTS-поиском, картой Leaflet
- **Telegram-плагин**: токен бота + список chat_id через панель
- Heartbeat включён по умолчанию (если пользователь захочет)
- Карта lat/lon на главной для новых лотов

### v3+ (отдельный проект)
- Хостинг на VPS, мульти-юзер
- PWA, Service Worker для фоновых уведомлений
- Регистрация оператора ПДн в РКН
- Code-signing exe (если пользователей >5)
- Дополнительные каналы (ntfy, Discord, SMS и т.д.)

## Известные ограничения MVP

**Уведомления приходят только когда браузер открыт И на ПК пользователь.**
- Вкладка `127.0.0.1:8080` открыта → видит мгновенно (SSE/polling + Notification API)
- Браузер закрыт → email на почту (если включён)
- ПК выключен → программа не работает, при включении догоняет

**Email — единственный канал push'а в MVP.** Если пользователь часто в дороге без email-почты в телефоне — попросит Telegram, добавим в v2.
