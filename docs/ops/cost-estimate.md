## Что отличается от предыдущей оценки

| Изменение | Эффект |
|---|---|
| Убран каталог из MVP | −5–6 дней / −50–70к ₽ |
| Убран Telegram-плагин из MVP | −0.5 дня / −3к ₽ |
| Убран PowerShell-фолбэк, auto-update, code-signing | −2 дня / −20к ₽ |
| Добавлено: single-instance, CSRF, hosts whitelist, lock-файл, idempotency notifier | +1 день / +10к ₽ |
| Добавлено: расширенный тест-план | +1 день / +10к ₽ |
| Добавлено: lazy enrichment-worker | +0.5 день / +5к ₽ |
| Добавлено: кросс-платформенность Win+Linux, CI matrix | +0.5 дня / +12к ₽ |

## Поддержка
- Хостинг: **0 ₽** (всё локально)
- Сопровождение: **5–8к ₽/мес**
- Срочные патчи (если селекторы сломались критично): входят в подписку
