# Реестр свободных лотов (`/cabinet/free-lot`)

**Ключевая страница для мониторинга.** Перечень доступных земельных участков по программе «Дальневосточный/Арктический гектар».

## URL и обязательные параметры
- Базовый URL: `https://xn--80aaggvgieoeoa2bo7l.xn--p1ai/cabinet/free-lot`
- **Обязательный** query param: `region={1|2}` — макрорегион (вероятно, 1 = Дальний Восток, 2 = Арктика). Без него → 500 «Ошибка 8».
- Пагинация: `&page=N`
- Доп. фильтры через `FreeLotSearch[...]` (см. ниже)

## Объём данных
- 10 строк на страницу (`per-page=10`, финальное решение — см. [[decisions-log]])
- Только для `region=1` — несколько сотен лотов. По всем регионам и фильтрам общий объём — несколько тысяч записей.

## Детальная карточка
`/cabinet/free-lot-view?id={data-key}` — страница конкретного участка. Содержит карту, точную геометрию, контакты ОГВ, документы.

## Фильтры (Yii2 ActiveForm)

Названия полей формы — `FreeLotSearch[*]`:

| Field | Назначение |
|---|---|
| `rfSubjectId[]` | Субъект РФ (multi) |
| `municipalId[]` | Муниципалитет |
| `settlementId[]` | Поселение |
| `assignmentOgvIds[]` | ОГВ |
| `landCategoryNames[]` | Категория земель |

Доп. компонент `FetreeModalForm` управляет деревом ВРИ (видов разрешённого использования).

## Pjax / AJAX
Таблица обёрнута в Yii2 GridView с PJAX-контейнером — обновление фильтров и пагинации идёт без перезагрузки страницы. Но при первой загрузке возвращается полный HTML — для парсинга **PJAX дёргать не обязательно**, достаточно обычного GET.

## Что мониторить
**Минимум:** новые `data-key` (появление новых лотов).  
**Полезно:** изменение полей `Статус` (13), `Дата актуализации` (12), `Аукцион` (14) у уже известных лотов.  
**Опционально:** падение количества (лот ушёл) — это тоже сигнал.

См. [[product/monitoring-plan]] для алгоритма парсера.
