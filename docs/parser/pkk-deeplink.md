# Deep-link на кадастровую карту по кадастровому номеру

> Как сформировать ссылку, по которой пользователь сразу попадает на нужный
> участок на публичной кадастровой карте ([[glossary#ПКК|ПКК]]).
> Нужно для перехода «лот → участок на карте» из каталога
> (см. [[parser/local-catalog]], раздел «ссылки на карты»).
> Это **внешние сервисы**, не наш API ([[web/api-reference]]).

## Вариант 1 — официальная ПКК Росреестра

```
https://pkk.rosreestr.ru/#/search/{lat},{lon}/{zoom}?text={кадастр}&type=1
```

Канон уже зафиксирован в [[parser/local-catalog]]. `type=1` — земельный участок.
Координаты/зум в hash задают стартовый вид; `text` — искомый номер.

## Вариант 2 — зеркало roscadastres.com (исследовано 2026-05-26)

Сайт `ik5map.roscadastres.com` — сторонняя обёртка над данными Росреестра
(не официальный сайт Росреестра). Deep-link короче и не требует координат:

```
https://ik5map.roscadastres.com/map.html?cn={кадастр}
```

Пример (проверен через Playwright — карта центрируется, зум до 10 м, всплывает
карточка участка с данными):

```
https://ik5map.roscadastres.com/map.html?cn=77:01:0006004:14
```

### Нюансы

- **Ссылку давать на `map.html`, а НЕ на `/map`.** Страница `/map` — лендинг-обёртка,
  карта встроена через `<iframe id="pkkmap" src="map.html?&v=91">` с жёстко прошитым
  `src`; параметр `?cn=` на `/map` **не пробрасывается** в iframe.
- Работает только параметр **`?cn=`**. Варианты `?text=`, `?q=`, `#номер` в hash —
  не парсятся.
- Двоеточия в номере передаются как есть, без URL-кодирования.

### Как устроено под капотом

При открытии `map.html?cn=…` код вызывает `docadastrsearch(cn)` →
последовательность запросов к собственному прокси `api.roscadastres.com/pkk_files/`:

| Шаг | Запрос | Назначение |
|---|---|---|
| 1 | `token.php?query={cn}&action=search` | proof-of-work challenge |
| 2 | `search3.php?query={cn}&action=search&type=1&timestamp=…&hash=…` | тип + id объекта |
| 3 | `geo2.php?cn={cn}` | геометрия (контур) участка |
| 4 | `data3.php?query=…&action=data&type=5&…` | атрибутивные данные для карточки |

Бэкенд кэширует/проксирует данные ПКК Росреестра.

## Рекомендация для проекта

**Основная ссылка в карточке лота и email-уведомлении** — зеркало `roscadastres.com`:

```
https://ik5map.roscadastres.com/map.html?cn={кадастр}
```

Построение URL централизовано в `src/fis_monitor/domain/map_links.py` (функция
`roscadastres_map_url`). Используется и в web-слое (`LotViewModel.url_cad_map`,
`web/sse_encoder.py`), и в email-уведомлениях (`infra/smtp/email_notifier.py`).
Кнопка / ссылка показывается только при наличии `cadastral_no`; координаты не нужны.

Официальная ПКК (`pkk.rosreestr.ru`) — исходный вариант, требует координат и
отображался кнопкой «На карту ПКК Росреестра». Заменён зеркалом (решение 2026-05-26)
в пользу более короткого deep-link без координат. Если зеркало станет недоступно —
откатить реализацию в `map_links.py`, вернув схему
`https://pkk.rosreestr.ru/#/search/{lat},{lon}/17?text={кадастр}&type=1`
(и добавив обратно `lat`/`lon` в условие).
