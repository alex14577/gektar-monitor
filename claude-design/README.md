# Монитор гектара — дизайн-пакет

Серверный UI на Jinja2 + HTMX + SSE. Без npm, без bundler'а. Файлы готовы под FastAPI: укажите `templates/` как директорию Jinja2 и `static/` для `StaticFiles`.

```
.
├── Monitor — main feed.html       # hi-fi демо главного экрана
├── Monitor — onboarding.html      # hi-fi демо 4-шагового онбординга
├── Wireframes.html                # эскизы (исследование, не для прода)
├── static/
│   ├── app.css                    # все стили, переменные, dark mode
│   └── app.js                     # age-ticker, copy, SSE-stub, IO, aria-live
└── templates/
    ├── base.html.jinja            # общий layout
    ├── feed.html.jinja            # главный экран
    ├── partials/
    │   ├── _header_status.html.jinja   # статус-чип в шапке (SSE-fragment)
    │   ├── _sidebar_filters.html.jinja # view-фильтры (НЕ хранятся в config)
    │   ├── _lot_poster.html.jinja      # poster-карточка (hot/warm)
    │   └── _lot_list.html.jinja        # list-карточка (cool/cold/gone)
    └── onboarding/
        ├── wizard.html.jinja      # full-screen takeover, 4 шага
        ├── _step1.html.jinja      # регионы
        ├── _step2.html.jinja      # SMTP бот-ящика
        ├── _step3.html.jinja      # email получателя
        └── _step4.html.jinja      # «готово»
```

## Mood-board

**Интонация.** Спокойный десктопный дашборд в духе Linear / Vercel / Stripe Dashboard. Чистая типографика, мягкие тени, скруглённые углы 10–14px, обильный whitespace. Никаких иллюстраций, мемоджи, glassmorphism, нескольких градиентов, неона.

**Палитра — light:**

| Назначение      | Hex / oklch                          | Использование |
|-----------------|--------------------------------------|---------------|
| Фон страницы    | `#f7f7f4`                            | `--bg` |
| Поверхность     | `#ffffff`                            | карточки |
| Поверхность-2   | `#f1f1ec`                            | код-блоки, hover |
| Линии           | `#e3e2dc` / `#cfcec6`                | `--line` |
| Текст           | `#14161a` / `#3a3d44` / `#6b6f78`    | ink / ink-2 / muted |
| **Акцент**      | `oklch(52% 0.12 158)` ≈ `#1c8156`    | primary CTA, статус OK |
| Hot (срочно)    | `#c5251c`                            | ≤ 10 мин, бордер, NEW-чип |

| Cool            | `#1d62c4`                            | 1 ч – 24 ч |
| Neutral         | `#8a8e96`                            | > 24 ч, архив |

Все цвета на белом проходят WCAG AA (≥ 4.5:1). Семантические статусы — приглушённые, не «светофор».

**Палитра — dark** (`prefers-color-scheme: dark`):

| Назначение  | Hex                                   |
|-------------|---------------------------------------|
| Фон         | `#0f1115`                             |
| Поверхность | `#161920`                             |
| Текст       | `#ecedef` / `#c8cad0` / `#8a8f99`     |
| Акцент      | `oklch(70% 0.13 158)` (ярче)          |
| Hot / Warm / Cool — те же оттенки в светлой версии, но мягче |

**Типографика.**
- Основной шрифт: **Inter** (Google Fonts) с фолбэком `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, sans-serif`.
- Моноширинный: **JetBrains Mono** с фолбэком `ui-monospace, "SF Mono", Menlo, Consolas, monospace`. Применяется **только** для кадастровых, координат, портов и счётчиков.
- Базовый размер `16px`, настраиваемый в `Настройках` (14/16/18) — переменная `--fs-base` на `:root`.
- `text-wrap: pretty` и `tabular-nums` для всех цифр-счётчиков.

**Скругления и тени.**
- `--r-sm: 6px` (кнопки, инпуты, чипы).
- `--r: 10px` (карточки лотов, zone, banner).
- `--r-lg: 14px` (модалки).
- Тени мягкие, в 2–3 слоя; в dark mode сильнее.

**Иконки.** SVG inline, стиль Lucide (тонкие линии, `stroke-width: 2`, скруглённые концы). Никаких SVG-иллюстраций — только функциональные глифы.

## Описание экранов

### 0 · Onboarding (4 шага)

Full-screen takeover. Виден один раз — пока `state.db` не отметит `onboarded=true`. По нижнему краю — `← Назад` слева, «Дальше →» справа, на шагах 2/3 — контекстная кнопка «Пропустить».

1. **Регионы.** Две большие карточки `Дальневосточный ФО` / `Арктическая зона`, чекбоксы изнутри (`aria-pressed`). По умолчанию обе выбраны.
2. **Почтовый ящик бота** *(новое требование)*. SMTP-настройки отдельного ящика, от которого будут уходить письма: host / port (587) / login (адрес) / password (со скрытием) / имя отправителя. Кнопка «Проверить подключение» (POST `/onboarding/smtp-test`). Подсказка с пресетами для Яндекс/Mail.ru/Gmail. Кнопка «Настроить позже» позволяет пропустить и доделать в `Уведомлениях`.
3. **Email получателя.** Куда слать письма — обычно личный адрес. Чек «отправить тестовое». Если пусто — только браузерные уведомления.
4. **Готово.** Подтверждение с чек-листом (регионы, бот-ящик, получатель, интервал). Кнопка «Открыть панель →».

### 1 · Главный экран — лента

Split-лейаут по «свежести» — был выбран вариант `D` из эскизов.

- **Sticky-шапка**: логотип, статус мониторинга (зелёный/жёлтый/красный с пульсирующей точкой), счётчик до следующей проверки, «Последний новый: N минут назад» (психологический якорь), кнопки `Проверить сейчас` / `🌙 Не беспокоить` / `Уведомления` / `Настройки`.
- **Sidebar (sticky)**: view-фильтры — субъекты, площадь, «только новые», «скрыть поданные», «★». Сверху read-only бейдж «Наблюдаю: ДФО, Арктика» со ссылкой на Настройки.
- **Health-виджет** под шапкой: «Последний цикл: 2 мин назад · Лотов: 1 247 · Последний новый: 6 ч назад».
- **Banners** — context-driven, появляются по SSE:
  - `banner--warn` за 10 мин до истечения сессии (`session.expires_soon`)
  - `banner--err` при ошибке цикла
  - `banner--info` для catch-up («пока вас не было: N новых»)
- **Zone «🔥 Горячее»** (≤ 1 часа) — карточки `.lot--poster` (большой тикающий таймер, полный набор CTA).
- **Zone «Сегодня»** (1 ч – 24 ч) — карточки `.lot--list` (плотные, раскрываются по клику; детали подгружаются лениво через `hx-trigger="revealed once"`).
- **Zone «Архив»** — кнопка «Показать ещё 1 234 старых лота» с пагинацией по 50.
- **Diff-карточки** (статус «лот ушёл») — `data-event="gone"`, серые, без CTA `Открыть`, только `Архивировать`. Звук — «pluck» (tier 3).
- **`aria-live="polite"`** на `#feed`, ассертивные сообщения — через `Monitor.announce(msg, true)`.

### 2 · Настройки

Карточки: `Расписание` (слайдер 0–60 мин, TZ, размер шрифта 14/16/18), `Область наблюдения` (макрорегионы — fetch-time, с предупреждением о докачке), `Поведение`, `Сессия ЕСИА`. Inline-save: «Сохраняется… ✓ Сохранено». Кнопка «Сохранить» зафиксирована внизу. *(Шаблон не включён в этот пакет — описание есть в эскизах, добавляется тем же паттерном что и `feed.html.jinja`.)*

### 3 · Уведомления

Карточки каналов: `Браузер` (Notification API, тест), `Email` (SMTP-настройки уже введены в онбординге — здесь только перенастройка), `Heartbeat в UI`, `Catch-up`. Отдельный блок «Фильтр уведомлений · notify-time» с подсказкой про разницу с view-фильтрами. История отправок снизу.

### 4 · История / диагностика

Таблица циклов (время, длительность, новых, статус, раскрытие → stack trace) + текстовые виджеты сверху (uptime, всего лотов, средняя длительность, тренд за 30 дней). Без графиков. Кнопка «Скачать диагностический архив» (zip без секретов).

## Минимальный JS — что где

`static/app.js` — одна self-invoked функция, без зависимостей.

| Функция / селектор                          | Что делает |
|---------------------------------------------|------------|
| `IntersectionObserver` + `setInterval(1s)`  | Тикает возраст лотов **только видимых** карточек. Возраст пересчитывается из `data-appeared-at` (epoch ms). Параллельно перекидывает `data-temp` при переходе ≤10м → ≤1ч → ≤24ч. |
| `IntersectionObserver` (threshold 0.6, 1s)  | Снимает бейдж `[NEW]`, когда карточка пробыла в зоне видимости ≥1 секунды. Заглушка `fetch('/lots/:id/seen', POST)` — раскомментировать или заменить на HTMX. |
| `[data-copy]`                               | Копирует значение в буфер + тост «Скопировано». Fallback через `document.execCommand`. Двойной клик на элемент с `data-copy` или на `.lot__cad` тоже копирует. |
| `[data-action="star"]`                      | Переключает `aria-pressed`. В шаблонах уже стоит `hx-post="/lots/:id/star"`. |
| `[data-action="expand"]`                    | Явная кнопка «▼ Детали». Но клик по любой «пустой» точке карточки (не по кнопке/ссылке) тоже раскрывает/сворачивает. С клавиатуры — Enter или Space на сфокусированной карточке. |
| `[data-action="pin"]`                       | Закрепляет/открепляет лот сверху своей зоны. Список закреплённых в `localStorage` под ключом `monitor:pinned`. |
| `[data-action="copy-md"]`                   | Копирует лот в Markdown-формате (заголовок, мета, кадастровый, ссылка). Для быстрой пересылки в чат. |
| `[data-density-option]` (auto/compact/poster)| Переключает `body[data-density]`, сохраняется в `localStorage`. `auto` — ориентация по возрасту лота (hot/warm → poster, cool → list). |нта с сервера. |
| `[data-action="expand"]`                    | Раскрывает details. У `.lot--list` сервер шлёт фрагмент по `hx-trigger="revealed once"`. |
| `[data-countdown]`                          | Header-таймер до следующего цикла, `interval_minutes` из конфига. |
| `[data-toggle-menu]` / `[data-menu]`        | Открывает поповеры (DND), закрывает при клике снаружи. |
| `keydown` `Esc` / `Enter`                   | Закрыть модалку / раскрыть карточку в фокусе. |
| `Monitor.announce(msg, assertive?)`         | Шепчет в скрытые `aria-live` регионы. `assertive` — для сессии и ошибок, `polite` — для новых лотов и тостов. |
| `playNotificationSound(tier)`               | Заглушка. Tier 1 «двойной pop» (подписанные субъекты), tier 2 «одинарный pop» (наблюдаемый макрорегион), tier 3 «pluck» (diff). Звуковые файлы кладите в `static/sfx/`. |
| `escalationStart()` / `escalationStop()`    | Эскалация без реакции: +60с громче, +180с — пульсирующий title `(N) ⚠ Монитор гектара` каждую секунду. Любой `click/keydown/focus` останавливает. |
| `onLotNew / onLotStatusChange / onCycleTick / onSessionWarn / onSessionExpired` | Точки входа для SSE. См. блок «SSE stub» в `app.js` — оставлен with-комментариями. |

**SSE-подключение** реализуется через HTMX в шаблонах: `<main hx-ext="sse" sse-connect="/sse/lots" sse-swap="lot.new">…</main>`. Сервер отдаёт уже готовый `<article class="lot">…</article>` через `_lot_poster.html.jinja` или `_lot_list.html.jinja` — JS делать ничего не надо, HTMX вставит фрагмент в начало `#feed`, а наш `IntersectionObserver` сам зарегистрирует новую карточку для тикера.

## SSE — события и фрагменты

Сервер на `sse-starlette` шлёт named events. HTMX по `sse-swap="X,Y"` подхватывает.

| Event             | Подключается через         | Фрагмент               | Куда вставляется |
|-------------------|----------------------------|------------------------|------------------|
| `status`          | `#header-status`           | `_header_status.html`  | `innerHTML` (sse-swap) |
| `lot.new`         | `#feed`                    | `_lot_poster` или `_lot_list` (зависит от temp) | `afterbegin` |
| `lot.status`      | `#feed`                    | `_lot_list` с `data-event="gone"` | `afterbegin` (или OOB-swap на конкретный `#lot-:id`) |
| `cycle.tick`      | `#header-status`           | `_header_status.html`  | (тот же канал, тот же sse-swap) |
| `expired`         | `#session-expired-modal`   | пустой div + `hx-swap-oob="attributes"` снимающий `hidden` | — |

Совет: для `lot.status` (диффы) лучше использовать **out-of-band swap** — фрагмент содержит `<div id="lot-:id" hx-swap-oob="outerHTML">…новый вид…</div>`, и старая карточка пересоздаётся на месте.

## Как добавить новый экран

1. Создайте `templates/<name>.html.jinja`, наследуйтесь от `base`:
   ```jinja
   {% extends "base.html.jinja" %}
   {% block sidebar %} … {% endblock %}   {# опционально #}
   {% block main %}    … {% endblock %}
   ```
2. Для частичных HTMX-фрагментов кладите файлы в `templates/partials/` с префиксом `_`. Возвращайте их с FastAPI как обычные `TemplateResponse` — браузер сам вставит по `hx-swap`.
3. Для full-screen экранов (wizard, expired-session) используйте `{% block fs %}` — это «забирает» страницу целиком, без header/sidebar.
4. Цвета и размеры — **только через CSS-переменные** (`var(--accent)`, `var(--r)`, `var(--surface)`). Это сохранит светлую/тёмную тему и шрифтовый размер из Настроек.
5. Иконки — inline SVG, copy-paste из Lucide или Heroicons. Никаких иконочных шрифтов.
6. Любая «живая» цифра (счётчик, возраст, время) — оборачивайте в `<span class="mono">…</span>` и в `tabular-nums`, чтобы не прыгала ширина.
7. Если экран должен реагировать на SSE — добавьте `hx-ext="sse" sse-connect="…" sse-swap="…"` на контейнер и пусть сервер шлёт уже отрендеренный фрагмент. JS не нужен.
8. Накладные ARIA-метки — обязательны: `role="region" aria-label="…"` на крупных блоках, `aria-live="polite"` на динамическом контенте, `aria-live="assertive"` — только для критичного (сессия, ошибки цикла).

## Дополнительные UX-улучшения (итерация 2)

Все новые поведения встроены в `static/app.js` и `static/app.css` — серверные изменения не требуются.

### Поведение карточек

- **Клик по любой «пустой» точке карточки** раскрывает/сворачивает детали. Клики по кнопкам/ссылкам/иконкам — продолжают делать своё. На картах «лот ушёл» отключено.
- **Двойной клик на кадастровом номере** копирует его (в дополнение к кнопке 📋).
- **Закрепление лота сверху** (`[data-action="pin"]`) — карточка перемещается под `zone__head` своей зоны и получает зелёный бордер + значок 📌. Список хранится в `localStorage` под ключом `monitor:pinned`. На стороне сервера ничего не меняется — pin это чисто клиентский UX.
- **Копировать как Markdown** (`[data-action="copy-md"]`) — формирует `**Заголовок**\nМета\n\`кадастровый\`\n[Открыть](url)` и кладёт в буфер. Удобно вставлять в Telegram / Slack.

### Контекстное меню

Правый клик по карточке — открывается компактное меню: **Открыть · Скопировать кадастровый · Скопировать как Markdown · Звезда · Закрепить · Заметка**. Меню само закрывается при клике вне, по Esc, и не показывается на «ушёл»-карточках.

### Лента

- **Sticky-пилюля «N новых сверху»** появляется, если по SSE пришёл новый лот, а пользователь скроллит ниже 200px. Клик — плавно скроллит к первому ещё непрочитанному. Реализована через `MutationObserver` + `htmx:afterSwap` — работает и с серверным prepend через HTMX, и с вручную добавленными карточками.
- **Soft-flash** для свежеприбывших лотов: `data-fresh="true"` ставится при появлении, через 2.4с снимается. Анимация — ring-pulse алым цветом + лёгкий подскок. Чтобы не дёргать глаз, новых лотов нельзя «скаскадировать»: каждый flash изолированный.
- **Сохранение позиции скролла** — `sessionStorage` под ключом `monitor:scroll:{pathname}`. Восстанавливается после reload и после `htmx:afterSwap`, если новая позиция оказалась около верха.

### Шапка

- **Escalation chip** — пилюля `#escalation-chip` рядом с countdown'ом. Показывает обратный отсчёт до следующей ступени эскалации звука («Громче через 0:43», «Title-pulse через 1:12», «Эскалация активна»). Появляется только когда `escalationStart()` вызван и реакции пользователя не было.

### Health-виджет

- **«Вы за лентой: 23 минуты»** — `data-since-arrived` тикает каждую секунду от момента открытия страницы. Психологический якорь, что мониторинг идёт фоном.

### Сайдбар

- **Переключатель плотности** `auto / плотно / постер` — устанавливает `body[data-density]`. По умолчанию `auto` (плотность по возрасту лота). `compact` ужимает poster'ы до 1.25rem-таймера и прячет ВРИ/ОГВ. `poster` разворачивает list-карточки в полные постеры. Хранится в `localStorage` под ключом `monitor:density`.
- Фильтр «Скрыть мои поданные» удалён (вместе с фичей «Я подал заявку»).

### Демо-контролы

В правом нижнем углу `Monitor - main feed.html` — три кнопки: «+ новый лот» (демонстрирует flash + пилюлю-счётчик, скроллите вниз и нажимайте), «эскалация» (показывает chip в шапке + начинает title-pulse через 3 мин — не ждите), «стоп». В Jinja-шаблонах этого блока нет — он только в hi-fi демо.
