# Мониторинг лотов «надальнийвосток.рф»

Сервис отслеживает новые свободные земельные лоты на сайте **надальнийвосток.рф** и мгновенно уведомляет в браузере и по email. Работает локально на вашем ПК — данные и ЕСИА-сессия не покидают компьютер. Открывается по адресу <http://127.0.0.1:8080>.

## Первый запуск

Мастер из 4 шагов: (1) регионы наблюдения, (2) SMTP — дефолтный бот-ящик сервиса или ваш собственный, (3) список email-получателей, (4) проверочное письмо. Email-шаги можно пропустить и настроить позже.

## Регионы и фильтры

В **Настройки → Регионы/Фильтры** выбираются субъекты ДФО/Арктики, минимальная площадь и другие критерии. Уведомления приходят только по лотам, прошедшим фильтр, и только один раз — без дубликатов.

## Как это работает

При старте сервис разово заполняет базу актуальным реестром по каждому выбранному региону. Дальше — фоновой цикл: запрос на регион с сортировкой по дате создания и ранним выходом на знакомом лоте. Новые лоты попадают в ленту и в уведомления через считанные минуты после публикации. Сервис распознаёт изменение схемы сайта-донора и предупредит, а не пропустит лоты молча.

## Уведомления

- **Браузер** — всплывающее уведомление и звук в открытой вкладке.
- **Email** — на ваши адреса, когда браузер закрыт. Опционально — ежедневная сводка.

При сбое доступны self-diagnostic экспорт и журнал запросов. Плагин-архитектура каналов: при необходимости подключаются Telegram, Slack, ВК, SMS.
