# Мониторинг лотов «надальнийвосток.рф»

Сервис отслеживает новые свободные земельные лоты на сайте **надальнийвосток.рф** и мгновенно уведомляет в браузере и по email. Запускается локально на вашем ПК; открывается по адресу <http://127.0.0.1:8080>.

## Первый запуск

Мастер из 4 шагов: (1) регионы наблюдения, (2) SMTP — дефолтный бот-ящик или ваш, (3) список email-получателей, (4) проверочное письмо. Email-шаги можно пропустить и настроить позже.

## Регионы и фильтры

В **Настройки → Регионы/Фильтры** выбираются субъекты ДФО/Арктики, минимальная площадь и другие критерии. Уведомления приходят только по лотам, прошедшим фильтр.

## Как это работает

При старте сервис разово заполняет базу реестром по каждому выбранному региону. Дальше — фоновой цикл: запрос на регион с сортировкой по дате создания и ранним выходом на знакомом лоте. Новые лоты попадают в ленту и уведомления через считанные минуты после публикации.

## Уведомления

- **Браузер** — всплывающее уведомление и звук в открытой вкладке.
- **Email** — на ваши адреса, когда браузер закрыт.

## Что повышает ценность

- Без дубликатов: уведомление по лоту приходит один раз.
- Авторизация через вашу ЕСИА-сессию; данные не покидают ПК.
- Свой SMTP или бот-ящик — на выбор.
- Опциональная ежедневная email-сводка, self-diagnostic экспорт, журнал запросов.
- Защита от смены схемы донора.
- Расширяемо: плагины под Telegram, Slack, ВК, SMS.
